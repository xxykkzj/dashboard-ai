Design tokens

Colours, type and spacing, and how to restyle the dashboard.

A design token is a named value: a colour, a font, a size. In CSS it is a custom property, written with two dashes. Every token lives in css/tokens.css, and the rest of the CSS only ever uses the names:

Change the value in one place and every bar, link and selected button follows. The swatches below show the values in the theme you are looking at now. Use Dark theme at the top of the page to see the other set.

      Data and actions

      Blue is the first data series and the colour of links. Copper is the second series. The pair was checked to stay distinguishable for colour-blind readers in both themes; if you change either, check again.

        Status

        Green, amber and red mean status and nothing else. They never colour a data series, and a status always comes with a shape and a word.

          Sequential scale

          Five steps of one hue for "how much": the map, the heat grid and the retention grid. --on-seq-lo and --on-seq-hi are the text colours to use on the light and strong steps.

            Type

            Two families with one rule: the serif (--font-display) is for headings and big figures, the sans (--font-ui) is for everything you read or operate. --font-mono is only for code and SQL.

            How light and dark work

            Light values sit on :root. The dark values are written twice, so that either the system setting or the theme button can decide:

            When you add or change a colour token

            Give it a light value on :root and a dark value in both dark blocks. If you forget one, the token keeps its light value in that case and you get dark text on a dark card.

            Restyle the dashboard

            1. Change the brand colours. In css/tokens.css change --mast (the band), --mast-hi (the copper) and --accent. Do the same in both dark blocks.
            2. Change the fonts. Edit --font-ui and --font-display, and the Google Fonts link in the <head> of index.html. Keep the fallback fonts after the first name.
            3. Change density. --fs-md sets body size; --r sets how round cards are.
            4. Check both themes and a phone width. In Chrome DevTools, the device toolbar sets the width, and Rendering then Emulate CSS prefers-color-scheme switches the theme.

            If you need to change how one component looks rather than a value, edit its block in css/components.css. Each block starts with a comment naming the component.
