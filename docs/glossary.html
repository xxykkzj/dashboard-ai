Glossary

Plain meanings for the terms used in the code and these pages.

Terms are listed alphabetically. Where a term has a page of its own, the page explains it in more depth: how the app works, design tokens, mock data.

#ACDEFHIJKLMPRSTV

#

95th percentile (p95)
The value that 95% of cases are at or below. Shows how slow the slow cases are.

A

Action level
The value below which a measure's status is Action. Set per measure in targets.json.
API
A web address a program can ask for data. Here, the service between the dashboard and Fabric that returns JSON for each view.
ARIA
Extra HTML attributes (aria-label, aria-pressed…) that tell screen readers what something is and what state it is in.

C

Cache
A store of answers already fetched, so the same question isn't asked twice. main.mjs keeps one per view and set of parameters.
Card
The framed box around one reporting item, built by cardHTML.
Cohort
A group of people who started in the same period, followed over time. The retention grid has one cohort per sign-up week.
Component
A reusable building block. Here, a function that draws into an element: lineChart, hbars, funnel.
Custom property
The CSS feature behind tokens: --name: value, read with var(--name).

D

D3
A JavaScript library for drawing with data. Used only for the council map's projection, shapes and zooming.
Data contract
The agreed list of views and the exact shape each returns. The mock source and the real API must both honour it.
Drill-down
Clicking a figure to see more detail about it, for example a service row opening that service's funnel.

E

ES module
A JavaScript file that uses import and export. Files end in .mjs here.
Event (data)
A campaign or incident from events.json, shaded on time charts.
Event delegation
One listener on a parent element handling clicks for many children, as main.mjs does for every data-state control.

F

Fabric
Microsoft Fabric, the analytics platform where the app's data is copied, cleaned and exposed as SQL views.
Funnel
A chart of how many people reach each step of a process, and how many stop between steps.

H

Hash
The part of an address after #. Changing it doesn't reload the page, so it is used to remember the tab.
Host
The element a component draws into, usually a card's .body.

I

Item (reporting item)
One card on the dashboard, described by one object with an id such as ITM-05.

J

JSON
A plain-text format for data: objects in { }, lists in [ ], names and text in double quotes.

K

KPI
Key performance indicator: a headline measure such as active users.

L

LGA
Local Government Area, the ABS term for a council area. The dashboard says "council".
Live region
An element whose text changes are read out by screen readers. Used to announce filter and slide changes.

M

Median
The middle value: half are below, half above. Less distorted by a few very slow cases than an average.
Mock data
Invented figures in data/mock/ that stand in for the real database while the dashboard is designed.

P

Projection
The method for drawing the curved earth flat. The map uses Lambert conformal conic.

R

RAG
Red, amber, green status. Here called Action, Watch and On track, and always shown with a shape and a word as well as a colour.
Registry
The list of all items, ITEMS in js/items/index.mjs. Tabs, cards, slides and the docs catalog are all built from it.
Render
To draw. Each item has a render function that turns data into HTML.
Retention
The share of people who come back. In the grid, the share of a sign-up week still using the app n weeks later.

S

Sequential scale
Light-to-strong steps of one colour used to show "how much".
Span
How many of the grid's 12 columns a card takes: s3 to s12.
State
The current choices (period, phone type, selected council…), held in js/state.mjs.
Suppression
Leaving out a figure because it covers too few people to be shown safely. Councils with fewer than 10 users are suppressed.
SVG
A way to draw shapes in HTML. The line and bar charts and the map are SVG.

T

Target
The value a measure is expected to reach. At or above it, status is On track.
Temporal table
A SQL Server table that keeps every past version of each row. Lets a query see what a record looked like on an earlier day.
Token (design token)
A named design value such as --accent. All tokens are in css/tokens.css.
TopoJSON
A compact file format for map boundaries. The council boundaries are stored in it.

V

View
A named question with an agreed answer shape, such as vw_ActiveUsers. Named after the SQL view that will answer it for real.
